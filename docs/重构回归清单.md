# 重构回归清单（R1–R12）· 可复用执行脚本

> 配套 `docs/重构计划-2026-09-11.md`。每阶段发布前逐项执行并记录结果。
> 环境：`node_modules/vite/bin/vite.js --host 127.0.0.1 --port <空闲端口>`，agent-browser 打开该地址。

## 0. 冒烟铁律（踩坑沉淀）

| 铁律 | 原因 |
|---|---|
| 查日历元素必须限定 `.calendar-view .day-cell` | **双网格并存**：DOM 中 70 个 `.day-cell`，35 个属隐藏经典网格；裸 `querySelector('.day-cell')` 会点到隐藏节点造成"假失败" |
| 状态按钮需先展开 `.detail-fold-head` | `.status-btn` 在折叠区内，默认不渲染 |
| 不要用 `button[data-status]` | 那是经典隐藏面板的按钮；Vue 面板用 `.status-btn` |
| 导航点击用 `.work-subnav button` | 底部/侧边栏有多个同名入口 |
| 主题切换后 sleep 1–2s 再读 `body.dataset.theme` | 主题应用含过渡（`startViewTransition`） |
| 每轮开始先挂 `window.__errs` 监听 | 判定"0 未捕获错误" |

## 1. 通用探针

```js
// 错误监听（每轮开头执行）
window.__errs=[];window.addEventListener('error',e=>window.__errs.push(String(e.message)));

// 主题令牌一致性（区域 A ↔ 区域 B）
(() => { const la=document.querySelector('.life-app'),cs=getComputedStyle(la),bs=getComputedStyle(document.body);
  return JSON.stringify({theme:document.body.dataset.theme,
    A_accent:bs.getPropertyValue('--accent').trim(), B_plum:cs.getPropertyValue('--plum').trim(),
    A_card:bs.getPropertyValue('--card').trim(), B_card:cs.getPropertyValue('--life-card').trim()}); })()
```
