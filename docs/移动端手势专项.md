# 移动端触控 / 手势专项（2026-07-25）

> 面向 Android 真机的触控手感升级。所有新代码均落在 Vue 路径（`src/composables`、`src/components`），未触碰 legacy 全局脚本。

## 新增模块

| 文件 | 作用 |
|------|------|
| `src/composables/useSwipe.js` | 统一指针滑动检测（触摸/鼠标/笔），支持横/纵、阈值、实时位移 `dx/dy`、setPointerCapture 跟手 |
| `src/composables/useLongPress.js` | 长按检测 + `navigator.vibrate` 震动反馈 + 移动容差取消，返回 `active` 供按压态 |
| `src/composables/usePullToRefresh.js` | 顶部下拉刷新（touch 事件 `passive:false` 阻止原生回弹），返回 `pullDistance/refreshing` |
| `src/components/ActionSheet.vue` | Teleport 到底部动作面板，标题+动作列表（含 danger 变体）+ 取消，安全区 padding，入场动画，`prefers-reduced-motion` 降级 |

## 集成点

- **日历页** (`CalendarView.vue`)：日历区包裹为 `swipeZone`，**左右滑动切月**（跟手位移 + 回弹）；**长按日格弹 ActionSheet 快速标记**（上班/休息/出差/请假/年假/病假/事假/清除），长按后抑制误触 click。
- **待办项** (`TodoItem.vue`)：根改为滑动视口，**左滑露出删除**（跟手位移，超阈值直接删 + toast）；**长按弹 ActionSheet**（完成/编辑/删除）；保留勾选/编辑/删除点击。
- **好友圈** (`SocialPage.vue`)：feed 滚动容器接 **下拉刷新**，顶部指示器（下拉刷新 / 释放刷新 / 刷新中）。
- **全局** (`App.vue`)：左边缘（x<20）滑动关闭浮层（派发 Escape 关闭 Reka 对话框）。
- **全局 CSS** (`styles.css`)：去点击高亮、滚动链收敛（`overscroll-behavior`）、滚动惯性、触控目标 ≥44px、≤400px/≤360px 小屏适配。

## 验证

- `npm run build` 通过（exit 0）。`@vueuse/core` 的 `INVALID_ANNOTATION` 为依赖 benign 警告，不影响产物。
- 手势逻辑全部为纯前端 Vue 组合式函数，不改动数据层 / IPC / 同步逻辑。

## 待真机验证（沙箱无法跑 Android）

- 月滑动跟手与回弹手感
- 长按震动是否触发（依赖设备 `navigator.vibrate` 支持）
- 左滑删除的阻尼阈值（当前 60px / 露白 120px）
- 下拉刷新在小屏机型（如 360px 宽）的触发区高度
- 边缘滑动关闭与底部导航点击的边界（x<20 仅 20px 热区，不影响正常操作）

## 双架构一致性

本专项为**纯新增**移动交互层，未修改既有日历/待办/同步业务路径；桌面端（Electron 鼠标）同样受益：长按（鼠标按住）、滑动删除（鼠标拖拽）在桌面可用，下拉刷新为触摸专属（桌面无此手势需求）。
